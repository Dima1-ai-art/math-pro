#  Math Pro

Приложение для решения математических задач с пошаговыми объяснениями.

##  Что умеет

###  Арифметика
- Калькулятор
- Дроби
- Проценты
- Степени
- Корни
- НОД и НОК
- Округление

###  Геометрия
- Площади фигур
- Периметры
- Объёмы
- Теорема Пифагора
- Тригонометрия (sin, cos, tg)

###  Статистика
- Среднее
- Медиана
- Мода
- Размах
- Дисперсия

###  Анализ
- Производные
- Интегралы
- Пределы

###  Алгебра
- Уравнения
- Системы уравнений
- Упрощение выражений
- Разложение на множители
- Раскрытие скобок

###  Комбинаторика
- Факториал
- Сочетания C(n,k)
- Размещения A(n,k)
- Перестановки P(n)

##  Установка и запуск

```bash
pip install -r requirements.txt
python main.py
